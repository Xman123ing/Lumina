# Lumina 功能说明文档 (Features)

## 1. UI/UX 设计 (UI/UX Design)
Lumina 采用精心打磨的 macOS 桌面端交互体验，视觉风格现代且沉浸。
- **视觉风格**：以深色模式（Dark Mode）为主基调，辅以高对比度的霓虹色（如紫蓝渐变）作为强调色。
- **玻璃拟物化 (Glassmorphism)**：大量使用 `NSVisualEffectView`（macOS 原生毛玻璃效果），背景呈现高透明度，透出桌面壁纸或底层窗口。
- **卡片式布局**：大圆角设计（12px - 16px），消除生硬的边界感。
- **排版**：使用系统字体（San Francisco）或高品质无衬线字体（如 Inter），字号层级分明，留白充足。

## 2. 交互形态 (Interaction Modals)

### A. 全局快捷翻译 (Quick Translate)
为追求极致效率的 Mac 用户设计的核心功能。
- **触发方式**：全局快捷键（如 `Option + Space` 或自定义）唤出。
- **Spotlight 风格浮层**：类似 Spotlight / Raycast 的居中悬浮窗，顶部为输入框。
- **实时输入联想**：输入后即时显示离线词典释义（下拉列表形式），支持使用键盘上下键 (`Up`/`Down`) 导航候选词。
- **快捷交互**：按 `Enter` 键确认并调用 AI 引擎进行深度翻译（或跳转主界面查看详细释义），失去焦点或按 `Escape` 键自动隐藏。

### B. 主窗口 (Main Window)
- **左侧边栏 (Sidebar)**：毛玻璃背景，包含：Translate (翻译)、History (历史记录)、Starred (生词本)、Settings (设置)。
- **右侧主区 (Main Area)**：上下分屏或左右分屏对比（原文 vs 译文）。支持长文输入、Markdown 渲染（针对 AI 输出的结构化内容）。
- **底部工具栏**：引擎切换（离线/DeepSeek/豆包等）、发音按钮、复制按钮。

## 3. 双引擎翻译系统

### 离线引擎 (Offline Engine)
Lumina 提供极速的本地离线查词体验，内置庞大的 ECDICT 词库。
- **双向查询**：支持中英互译，输入英文或中文均可匹配，支持前缀匹配与模糊搜索。
- **详尽释义**：展示单词的音标（美音/英音）、词性、常用中文释义及英文释义。
- **智能形态推断**：自动推断并展示单词的其他形态（复数、第三人称单数、过去式、现在分词）。

### AI 引擎 (AI Engine)
针对段落、长句或专业文献的翻译需求。
- **模型支持**：支持配置兼容 OpenAI 格式的 API Key 和 Base URL，预设主流模型选项（DeepSeek, 豆包, 通义千问, Kimi 等）。
- **自定义 Prompt**：支持自定义提示词（如：“你是一个专业的 IT 翻译，请将以下内容翻译为中文，保持专业术语不翻译...”）。
- **流式输出 (Stream)**：支持流式输出，实现打字机效果，减少等待焦虑。

## 4. 快捷操作与工作流
- **划词翻译**：选中文本后按下快捷键，自动提取文本并在快捷窗口中显示翻译结果（规划中）。
- **历史与生词本**：
  - 自动记录最近的 1000 条翻译历史。
  - 一键点击星号（Star）加入生词本，支持导出为 CSV 或 Anki 格式（规划中）。

## 5. 语音朗读 (TTS)
提供原生的语音合成能力，帮助用户掌握正确发音。
- **原生发音**：基于 macOS 的 `AVSpeechSynthesizer`，无需额外下载语音包。
- **多口音支持**：支持美音 (`en-US`) 和英音 (`en-GB`) 的单词朗读。
- **中文朗读**：支持长文本翻译结果的中文 (`zh-CN`) 朗读。

## 6. 词库管理
灵活的词库管理机制，满足不同用户的需求。
- **自动安装内置大词库**：首次启动时，如果本地数据库不存在或过小，Lumina 会自动安装/替换为内置的 ECDICT 大词库。
- **自定义导入**：支持在 `Settings` 中导入自定义的 TSV/CSV 格式词典，扩展本地词库。
- **命令行导入工具**：提供 `Scripts/import_ecdict_csv.py` 脚本，方便批量导入大规模词库。
