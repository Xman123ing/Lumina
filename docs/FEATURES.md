# Lumina 功能说明文档 (Features)

## 1. 主窗口功能

### 1.1 Dictionary

- 输入关键词后按回车执行检索
- 展示常用释义、英文释义、词形推断
- 支持候选词列表与点击回填
- 查询结果采用分区卡片与渐进动画
- 长内容通过滚动展示，不强制拉伸窗口

### 1.2 Long Text

- 输入长文本后点击 `Ask AI` 翻译
- 显示翻译中阶段状态
- 结果区支持复制、朗读、滚动
- 支持源文本朗读与字符数统计

### 1.3 Settings

- AI Provider / Base URL / Model / API Key / System Prompt 配置
- Quick Translate 全局快捷键录制与恢复默认
- 朗读角色选择（语音风格预设）
- 导入 TSV/CSV 词典
- AI 配置保存成功 Toast

## 2. Quick Translate（独立迷你窗）

- 使用独立 `NSPanel`，非主窗口内嵌层
- 默认模式为 Dictionary，可通过左侧 `+` 切换 Long Text
- 输入框支持自动聚焦、Esc 关闭、失焦自动退出
- 每次唤起重置状态（默认模式 + 空输入 + 空结果）
- 结果展示规则：
  - 仅在下方展开结果区域
  - 输入行与左侧 `+` 按钮位置保持稳定
  - 内容超出可视区时通过滚动查看

## 3. 菜单栏与窗口行为

- 应用关闭按钮行为为后台驻留
- 菜单栏图标支持打开 Quick Translate、打开主窗口、退出应用
- 主窗口支持鼠标拖拽调整大小

## 4. 词库与数据

- 内置 `builtin_dictionary.sqlite3`（ECDICT）
- 首次启动自动部署到用户目录
- 支持命令行脚本导入大规模词库
- 支持应用内导入自定义 TSV/CSV

## 5. 语音能力（TTS）

- 基于 macOS 原生语音合成
- 支持英文（美/英）与中文朗读
- 支持角色预设，提高不同语气辨识度
