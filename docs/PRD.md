# Lumina 产品需求文档 (PRD)

## 1. 产品定位

Lumina 是一款面向 macOS 的原生翻译工具，提供：

- 离线词典极速查词（本地 SQLite / ECDICT）
- AI 长文本翻译（OpenAI 兼容接口）
- Spotlight 风格 Quick Translate 迷你窗
- 菜单栏常驻与全局快捷键工作流

核心目标是“**快、准、顺滑**”：查词快、翻译准、交互不打断。

## 2. 目标用户

- 日常阅读英文资料、代码、论文的开发者与学习者
- 需要中英文高频切换的内容创作者与产品人员
- 对 macOS 原生体验、快捷键效率、隐私本地化有要求的用户

## 3. 当前版本范围（已实现）

### 3.1 主窗口功能

- Dictionary 模式：本地词典检索、候选词、常用释义、英文释义、词形推断
- Long Text 模式：输入长文本并调用 AI 翻译，支持复制与朗读
- Settings：AI 配置、快捷键配置、朗读角色配置、词库导入
- History / Starred 入口与基础界面骨架

### 3.2 Quick Translate

- 全局快捷键唤起独立 `NSPanel` 迷你窗（非主界面 overlay）
- 默认 Dictionary，支持切换 Long Text
- 输入框自动聚焦、Esc 关闭、失焦自动隐藏
- 结果区支持滚动，内容超出时可浏览全部结果
- 每次唤起为干净状态（不保留上次输入和结果）

### 3.3 系统级能力

- 菜单栏图标常驻，支持快速唤起 Quick Translate / 打开主窗口 / 退出
- 点击主窗口关闭按钮默认后台运行（符合菜单栏工具形态）
- TTS 朗读支持多语言与角色预设
- 配置持久化（`UserDefaults` + JSON 文件）

### 3.4 交付与分发

- 提供 `Scripts/package_dmg.sh` 一键生成 Release DMG
- DMG 安装体验为标准拖拽安装（App -> Applications）

## 4. 非目标（当前版本）

- 浏览器划词自动翻译
- 云端账户与跨设备同步
- 多语种词库体系（中英以外）

## 5. 成功指标

- Quick Translate 唤起与可输入延迟低于 150ms（体感无阻塞）
- 本地词典查询体感即时（常规查询 < 50ms）
- AI 翻译操作路径短：输入 -> 翻译 -> 复制/朗读闭环可在单页完成
