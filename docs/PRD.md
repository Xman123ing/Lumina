# Lumina 产品需求文档 (PRD)

## 1. 产品概述 (Product Overview)
**Lumina Translate** 是一款专为 macOS 设计的原生翻译应用，兼具离线词库查询与前沿 AI 大模型（DeepSeek、豆包、千问等）的长文翻译能力。它致力于为用户提供极速、沉浸式的查词与翻译体验，同时兼具本地数据安全与未来 AI 扩展能力。

## 2. 目标用户
- **高频查词用户**：阅读英文文档、论文或进行开发工作，需要频繁查阅单词释义的 Mac 用户。
- **长文本翻译用户**：需要快速翻译段落或长文本，且对翻译质量要求较高的用户。
- **追求极致体验的用户**：偏好 macOS 原生设计、沉浸式 UI（如玻璃拟物化）以及快捷键交互的高级用户。
- **离线与隐私敏感用户**：希望在无网络环境下也能使用基础翻译与查词功能，且注重数据隐私的用户。

## 3. 核心价值 (Core Value)
- **极致的 UI 体验**：采用类似 Discord 的现代美学设计，深度融合 macOS 原生毛玻璃（亚克力）效果、高透明度与大圆角卡片，提供沉浸式视觉体验。
- **双引擎驱动**：
  - **离线可用**：内置千万级本地词库（ECDICT），基于 SQLite 提供毫秒级的本地词典检索，无网状态下依然支持单词、短语的极速查询。
  - **AI 赋能**：支持配置主流大模型 API，精准处理长句、长文、专业文献，结合语境提供高质量翻译。
- **用完即走**：全局快捷键唤出类似 Spotlight 的快捷窗口，无缝融入用户日常工作流，不打断当前思路。

## 4. 需求范围与优先级

### P0 (核心功能，已实现)
- **本地词典查词**：支持中英双向查询，展示音标、释义及候选词。
- **全局快捷翻译 (Quick Translate)**：悬浮输入框，支持快捷键唤出及实时联想。
- **长文本翻译**：支持本地逐词回退翻译，以及 AI 翻译引擎的接入框架。
- **语音朗读 (TTS)**：支持美音、英音及中文的原生语音合成。
- **词库管理**：首次启动自动安装内置大词库，支持导入自定义 TSV/CSV 词典。

### P1 (重要功能，规划中/部分实现)
- **AI 引擎与流式输出**：完善 DeepSeek/豆包/千问 等大模型的 API 调用与配置界面，支持流式输出（Stream）和自定义 Prompt。
- **历史记录 (History)**：自动记录最近的 1000 条翻译历史，方便回溯。
- **星标生词本 (Starred)**：允许用户收藏生词，支持导出为 CSV 或 Anki 格式。
- **全局快捷键绑定**：允许用户自定义唤出 Quick Translate 的全局快捷键。

### P2 (扩展功能，规划中)
- **划词翻译**：在其他应用中选中文本后，通过快捷键直接提取文本并在快捷窗口中显示翻译结果。
- **多语言支持**：扩展除中英之外的其他语言词典与翻译能力。
- **UI 定制**：毛玻璃透明度调节、主题色切换。

## 5. 实施规划 (Roadmap)
- **Phase 1: 视觉与原型**：搭建 SwiftUI 工程，配置无边框、毛玻璃主窗口与快捷悬浮窗。实现基础 UI 组件与全局快捷键逻辑。
- **Phase 2: 离线引擎集成**：准备 SQLite 离线词库，实现极速查询接口，绑定 UI 实现即时联想与基础翻译。
- **Phase 3: AI 引擎与流式输出**：开发 LLM API 客户端，支持 SSE 流式解析，添加模型切换和自定义 Prompt 功能。
- **Phase 4: 完善与发布**：实现历史记录与生词本功能，完善划词翻译逻辑，进行性能优化与打包签名 (Notarization)。

## 6. 成功指标 (Success Metrics)
- **查词响应时间**：本地词典查询响应时间 < 50ms。
- **快捷唤出体验**：Quick Translate 唤出延迟 < 100ms，输入联想无卡顿。
- **用户留存**：核心用户的高频使用率（日均查词/翻译次数）。
